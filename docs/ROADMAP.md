# Engawa ロードマップ（提出後の予定）

> 現時点（2026-10-09）で**実装済み**のものと、**これから**のものを分けて書く。これからのものは、実装も契約もしていない。

## 本人の基本情報を、窓口で書き写す手間を減らす（段階的に）

| 段階 | 内容 | 状況 |
|---|---|---|
| 1 | 本人が入力した基本情報（氏名・住所・電話など）を、**本人の端末にだけ**保存。窓口に見せるかは、見せる画面でそのつど選ぶ。項目ごとにコピー。マイナンバー等の12桁以上の数字は入力できない | **実装済み** |
| 2 | 持ち物の案内：「本人確認書類は、窓口によって、顔写真つき1点、または2点の組み合わせ」などを、窓口に確認するための一覧で案内する（書類は預からない） | 検討中 |
| 3 | 本人確認事業者（公的個人認証に対応した事業者）を通じて、本人の同意のうえで、**基本4情報（氏名・住所・生年月日・性別）だけ**を受け取る。**個人番号は取得しない。身分証の画像は預からない** | 未契約。通過後に、費用・審査・条件を確認する |

### 預からないもの（理由）
- **マイナンバー（個人番号）**: 番号法により、法律で定められた手続以外では、本人の同意があっても、収集・保管できない。
- **身分証の画像（免許証・保険証・パスポート・公共料金の通知など）**: 本籍・番号などが写り込む。預かる責任が重く、「診断も、個人を特定する情報の保存もしない」という約束とも矛盾する。窓口が原本の確認を求める場合も多く、写しで足りるかは、窓口による。
- 実際に導入するときは、法律の専門家か、認定事業者に確認する。

## 窓口を増やす（成長の仕組み）
- **実装済み**: 引き継ぎのあとに、次の窓口へ渡す**招待コード**。受け取った窓口は、無料パイロットの特典（試行期間中の利用料なし、導入の初期設定の代行、試行結果レポート）を受けられる。
- **これから**: 試行の実測（カード作成時間、引き継ぎを受け取れた割合）をレポートにする。紙の手帳キット（QR つき）。

## 守ること
- 本人から課金しない。広告・データ販売・トークン・困りごとのゲーム化は入れない。
- 効果は、実測してから言う。現時点で、実測値は、まだない。
