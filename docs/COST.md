# Engawa 費用対効果の試算（1枚）

> 作成日: 2026-10-09。為替は **1ドル=150円** と仮定。料金は Google Cloud 公式の料金ページ（2026-10-09 確認）による。
> **実測**は、実際の呼び出しで測ったトークン数。**仮定**は、利用規模などの想定で、実測ではない。

## 1. 1回あたりの費用（実測トークン × 公式料金）

| 処理 | 実測（入力 / 出力トークン） | 1回の費用 | 備考 |
|---|---|---|---|
| 次の質問を考えるAI（Gemini 2.5 Flash） | 約236 / 約36（3回測定） | 約 **0.024円** | 入力 $0.30、出力 $2.50 / 100万トークン |
| 次の相談先の提案（Gemini 2.5 Flash＋Google検索） | 約146 / 約460（3回測定） | 約 **0.18円** | 検索の根拠づけは、1日1,500回まで追加料金なし（超過は公式表に従う） |
| 音声入力（Speech-to-Text v1・標準） | 最大55秒 | 20秒で約 **1.2円**、55秒で約 **3.3円** | 月60分は無料。以降 $0.024/分 |
| 入力・出力の安全チェック（Model Armor） | 1件あたり約900トークン | 約 **0.014円** | 月200万トークンまで無料。以降 $0.10/100万トークン |

## 2. 1件の相談（本人1人分）あたり

- 典型例（質問3回＋相談先1回＋音声1回＋安全チェック）: **約1.5円**
- 音声を使わない場合: **約0.3円**
- 実行基盤: Cloud Run（1 vCPU・512MiB・最大2台・待機0台）。リクエストがない間は課金されない。現在の利用量は、無料枠の範囲に収まる見込み（月180,000 vCPU秒・360,000 GiB秒・200万リクエスト）。
- 保存: Firestore（引き継ぎは30日、試行データは90日、パイロット申込は180日で自動削除）。無料枠の範囲。

## 3. 規模を広げたときの概算（**仮定**。実測ではない）

仮定: 1窓口が1日20件、月20営業日 = **1窓口あたり月400件**。無料枠は差し引かず、多めに見積もる。

| 窓口数 | 月の相談件数 | 音声を全員が使う | 音声を3割が使う |
|---|---|---|---|
| 1 | 400 | 約600円 | 約260円 |
| 10 | 4,000 | 約6,000円 | 約2,600円 |
| 100 | 40,000 | 約60,000円 | 約26,000円 |

→ **1窓口あたり月 約260〜600円** の変動費。費用の大半は音声入力で、AIの呼び出しは1件0.3円ほど。
→ 本人は無料のまま、窓口側の運営費（1窓口 月数百円〜）を、自治体の委託や助成で賄う設計と整合する。

## 4. 費用を抑える仕組み（実装済み）

- Cloud Run は、待機0台・最大2台。使わない間は課金されない。
- 呼び出しの回数制限（相談先の提案: 1分6回、音声: 1分12回）。
- 音声は1回55秒まで。AIの出力は上限トークンを設定。
- 予算アラート: 月3,000円。

## 5. 正直な限界

- 上の1回あたりの費用は、**小さな見本での実測**（各3回）。入力が長い相談では、増える。
- 規模別の表は、**仮定に基づく概算**。実際の利用件数は、試行で測ってから見直す。
- 検索の根拠づけの超過料金、Cloud Run の超過分は、規模が大きくなったときに公式料金表で再計算する。
- 請求の実績は、Cloud Billing の画面で別途確認する。
